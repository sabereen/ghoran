# وضعیت واقعی اجرای استخراج

آخرین snapshot پایدار و کنترل‌شده در ۲۰۲۶-۱۰-۲۲ شامل **۶۵٬۱۴۵ مورد از ۸۱٬۰۶۸ مورد** است: **۶۵٬۱۳۵ موفق، ۱۰ نامعتبر، صفر 404/410، صفر خطای موقت و صفر HTTP دیگر**. **۱۵٬۹۲۳ مورد در این snapshot بررسی نشده‌اند.** این خروجی کامل معرفی نمی‌شود.

استخراج واقعاً اجرا شد و آخرین پیشرفت مشاهده‌شدهٔ اجرای زنده از ۷۰ هزار مورد گذشته بود، اما محیط Work با خطای `409 environment_offline` قطع شد. پیشرفت بعد از snapshot پایدار، بدون دسترسی مجدد به همان محیط قابل تأیید و انتشار نیست.

آرشیو قابل ادامهٔ ارائه‌شده در خروجی این مأموریت شامل SQLite و تاریخچهٔ رویدادها، JSONL اندازه‌گیری‌ها، تحلیل‌ها، چهار سناریوی Gain، گزارش فارسی و نمودارهای به‌روز همین snapshot است. schema و بررسی معنایی تمام ۶۵٬۱۴۵ رکورد و توصیه‌های متناظر بدون خطا گذشت. ۱۷ تست Python و ۱۵۱ تست مخزن نیز پیش از قطع اتصال گذشتند.

ده نامعتبر شامل هشت مورد خطای جزئی Decode، یک فایل خالی و یک شکست probe است. خروجی PCM جزئی، اندازه‌گیری معتبر برای Gain تلقی نشده است.

در معیقلی فایل‌هایی با پسوند mp3 و Codec واقعی PCM شناسایی شدند. هدر نمونهٔ ۲:۱ با درخواست ۶۴ بایتی، RIFF/WAVE بودن آن را تأیید کرد؛ این به خودی خود خرابی صوت نیست. مدرک در metadata/format-audit.json ثبت است. هیچ فایل اصلی تبدیل، نرمال‌سازی یا دوباره MP3 نشده است.

**تفکیک snapshotها:** دادهٔ consumer فعلی داخل data و گزارش‌های پیش‌تر commit‌شده، snapshot اولیهٔ ۹٬۵۳۷ موردی هستند و provisional باقی می‌مانند. آن‌ها را با آرشیو ۶۵٬۱۴۵ موردی یکی ندانید. به‌روزرسانی bulk export نهایی و اجرای ۱۵٬۹۲۳ مورد باقی‌مانده، تا اتصال مجدد محیط ناتمام است. PR به همین دلیل draft می‌ماند. کد نهایی بازبینی فرمت و تولید گزارش HTML مستقل حفظ شده، ولی export نهایی پس از قطع اتصال اجرا/تأیید نشده است.

ادامهٔ کار باید از checkpoint موجود صورت بگیرد، نه از دیتابیس خالی. راهنمای بازتولید و Resume در README تحلیل حفظ شده است؛ ادامهٔ اجرای این مأموریت برعهدهٔ دستیار است و از کاربر اجرای کد درخواست نشده است.
