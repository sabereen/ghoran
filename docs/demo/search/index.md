# جستجوی زنده در قرآن

عبارت عربی مورد نظر را بنویسید یا نوع جستجو را تغییر دهید. پس از مکث کوتاه در
تایپ، نتیجه‌ها خودکار به‌روز می‌شوند؛ با دکمهٔ «جستجو» یا کلید Enter نیز می‌توانید
جستجو را فوراً اجرا کنید.

جستجو روی متن تنزیل انجام می‌شود و نتیجه‌ها با رسم‌الخط حفص نسخهٔ ۳ نمایش داده
می‌شوند. بخش‌های مطابق با عبارت جستجو هایلایت می‌شوند. تعداد کل آیه‌های پیدا‌شده
نمایش داده می‌شود و برای سبک ماندن دمو، حداکثر ۱۰ نتیجه می‌بینید.
