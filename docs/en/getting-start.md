# Getting started

Ghoran is a collection of libraries for building client-side Quran web applications. It provides Quran text in several orthographies, fonts, metadata and tools for working with that content.

There is still plenty to do, and contributions are welcome.

## Quran entities

Classes such as Ayah and Surah make Quran data easier to use.

Read more: [@ghoran/entity](/en/packages/entity).

## Quran metadata

Surahs, pages, juz divisions, obligatory and recommended prostrations, and more.

::: warning Prefer the entity package for application development
The metadata package exposes low-level data. Use the entity package for a more convenient interface.
:::

Read more: [@ghoran/metadata](/en/packages/metadata).

## Text and fonts

Quran text in several orthographies, together with fonts for displaying it.

Read more: [@ghoran/text](/en/packages/text).

## Quran search

Search verses, restrict the scope, highlight matches and run searches in a browser worker.

Read more: [@ghoran/search](/en/packages/search).

## Translations

Verse-aligned Quran translations provided as JSON files.

Read more: [@ghoran/translation](/en/packages/translation).

See [source licenses and acknowledgements](/en/appreciation) before using the supplied texts and fonts.
