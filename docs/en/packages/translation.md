# Quran translations — `@ghoran/translation`

This package provides Quran translations.

## Installation

```bash
npm i @ghoran/translation
```

## Tanzil translation licenses

Translations with names starting with `tanzil` come from [Tanzil's translation page](https://tanzil.net/trans/). That page explains the terms of use, summarized here:

1. Only noncommercial use is permitted; contact the translator or publisher for commercial use.
2. If you use more than three translations, include a link to https://tanzil.net/trans in your application.
3. Redistributing the entire translation collection requires Tanzil's permission.

## Usage

The translations are available as JSON files.
