# Quran entities

This package provides JavaScript classes for working conveniently with entities such as verses (Ayah) and chapters (Surah).

## Installation

::: code-group

```bash [npm]
npm i @ghoran/entity
```

```bash [pnpm]
pnpm add @ghoran/entity
```

```bash [yarn]
yarn add @ghoran/entity
```

:::
